## 一、色彩系统（Color System）

```css
:root {
    /* === 背景 === */
    --bg-primary:        #fcfdff;   /* 暖白基底 — 主背景色 */
    --bg-card:           #ffffff;   /* 纯白卡片 */
    --bg-section-alt:    #f5f7fc;   /* 浅灰蓝隔行色 */

    /* === 主色（冷） === */
    --navy-dark:         #0f1a3a;   /* 最深海军蓝 — 标题/装饰块 */
    --navy:              #17202f;   /* 海军蓝 — 正文区域/轮廓 */
    --navy-mid:          #1e2d4a;   /* 中海军蓝 — 次级标题 */

    /* === 强调色（暖） === */
    --orange-burnt:      #ef6026;   /* 烤橙 — 核心强调/高亮 */
    --orange-dark:       #d4511e;   /* 深橙 — hover/active 状态 */
    --salmon:            #fdceba;   /* 鲑鱼粉 — 装饰卡片底色 */
    --salmon-light:      #ffe4d8;   /* 浅鲑鱼粉 — 轻量底色 */
    --tan:               #f8c6a1;   /* 浅棕色 — 暖调点缀 */
    --tan-light:         #fbe5cc;   /* 浅米棕 — 氛围背景 */

    /* === 辅助色（冷暖过渡） === */
    --blue-bright:       #3462c4;   /* 明亮蓝 — 图标/标签/副强调 */
    --blue-mid:          #4a75d0;   /* 中蓝 — hover 状态 */
    --blue-light:        #7ba1e8;   /* 浅蓝 — 引用块/背景标注 */
    --blue-subtle:       #dce6f8;   /* 极浅蓝 — 表格表头/卡片背景 */

    /* === 文字色 === */
    --text-primary:      #1a1f2e;   /* 主文字 — 接近纯黑的海军 */
    --text-secondary:    #4a5064;   /* 副文字 — 深灰 */
    --text-muted:        #8e93a4;   /* 弱文字 — 注释/辅助信息 */
    --text-on-dark:      #f0f2f5;   /* 深色背景上的文字 */

    /* === 边框 === */
    --border:            #e8ebf0;   /* 默认边框 */
    --border-light:      #f0f2f6;   /* 弱边框 */
}
```

**配色逻辑**：
- 🔵 海军蓝家族（navy-dark → mid）→ 专业感 · 信任 · 深度
- 🟠 橙+粉+棕家族 → 温度 · 活力 · 人性化
- 🔷 亮蓝家族 → 桥梁色，连接冷暖和品牌调性

## 二、布局规范（Layout System）

### 2.1 页面比例

```
┌──────────────────────────────────────┐
│  留白区域 (上)                         │
│                                      │
│  ┌────────────┐  ┌────────────────┐  │
│  │            │  │                │  │
│  │  装饰区     │  │  内容区        │  │
│  │  非对称色块 │  │  文本/数据     │  │
│  │  几何图形   │  │  列表/卡片     │  │
│  │            │  │                │  │
│  └────────────┘  └────────────────┘  │
│              ↑                      │
│         非对称分割线                  │
│  留白区域 (下)                        │
└──────────────────────────────────────┘
```

### 2.2 核心布局规则

| 规则 | 描述 |
|------|------|
| **非对称分割** | 左 1/3 装饰区 + 右 2/3 内容区，或反之 |
| **装饰色块** | 几何色块（圆形/圆角矩形/不规则形状）在装饰区穿插 |
| **留白优先** | 上下边距 ≥ 总高度的 10%，左右 ≥ 5% |
| **内容居中** | 文本/数据内容在右侧区域垂直居中 |
| **标题区** | 采用海军蓝 + 留白的大号标题，配装饰元素 |

### 2.3 每页内容密度限制

| 页面类型 | 最大内容 |
|----------|---------|
| 封面 | 1 标题 + 1 副标题 + 3~4 标签 |
| 内容页 | 1 标题 + 1 装饰区 + max 5 要点 或 1 数据表 |
| 对比页 | 2 组对比（左右或上下） |
| 数据页 | 1 表格 + 1 结论框 |
| 趋势/洞察 | 4~6 条 + 总结框 |

## 三、排版规范（Typography System）

### 3.1 字体方案

```css
/* 方案一：中文字体（推荐） */
--font-display: 'Noto Serif SC', serif;   /* 标题 — 优雅衬线增加品质 */
--font-body:    'Noto Sans SC', sans-serif; /* 正文 — 清晰无衬线 */

/* 方案二：英文字体（适配 Google Fonts） */
--font-display: 'Fraunces', 'Noto Serif SC', serif;
--font-body:    'Inter', 'Noto Sans SC', sans-serif;
```

### 3.2 字号缩放（clamp 规则）

```css
--title-size:  clamp(1.5rem, 5vw, 3.5rem);   /* 封面标题 */
--h2-size:     clamp(1.1rem, 3vw, 2.2rem);    /* 页面标题 */
--h3-size:     clamp(0.9rem, 1.8vw, 1.4rem);  /* 子标题 */
--body-size:   clamp(0.7rem, 1.3vw, 1rem);    /* 正文 */
--small-size:  clamp(0.6rem, 0.9vw, 0.8rem);  /* 辅助文字 */
--tiny-size:   clamp(0.5rem, 0.75vw, 0.7rem); /* 注释 */
```

### 3.3 间距系统（8分网格）

```css
--slide-padding: clamp(1.2rem, 4vw, 3.5rem); /* 页面内边距 */
--content-gap:   clamp(0.5rem, 1.5vw, 1.5rem);/* 内容块间距 */
--element-gap:   clamp(0.25rem, 0.8vw, 0.8rem);/* 内部元素间距 */
--card-padding:  clamp(0.8rem, 1.5vw, 1.5rem);/* 卡片内边距 */
```

## 四、视觉元素规范（Visual Elements）

### 4.1 装饰元素

| 元素 | 实现 | 使用场景 |
|------|------|---------|
| **几何色块** | `border-radius: 50%;` 或 `rounded-[16px]` | 左侧装饰区的不规则排布 |
| **装饰圆点** | `width: 12px;` 半透明 | 背景散落，增加层次感 |
| **色条分隔线** | `height: 3px; border-radius: 3px;` | 标题下方 |
| **数字 sticker** | 圆形容器 + 衬线数字 | 编号/流程/趋势列表 |
| **标签 pill** | `border-radius: 20px;` 彩色背景 | 模型标签/场景分类 |

### 4.2 卡片与容器

```
┌─ 白色卡片 ───────────┐
│   圆角 12px           │
│   微阴影               │
│   左边框色条（海军蓝）  │
│   内部 16px padding    │
└───────────────────────┘
```

### 4.3 表格风格

- 白色底 + 浅蓝表头（`#dce6f8`）
- 隔行浅灰（`#f8f9fc`）
- 圆角 10px
- 高亮值用 `--orange-burnt` 或 `--blue-bright`

### 4.4 评分/进度条

- 圆角厚条（`height: 10px; border-radius: 20px;`）
- 渐变填充：`linear-gradient(90deg, orange, salmon)`
- 底色：`#e8ebf0`

## 六、动画规范

```css
--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);  /* 缓出 — 专业感 */
--ease-out-back: cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹跳 — 温暖感 */
--duration-normal: 0.6s;   /* 标准入场 */
--duration-slow: 0.8s;     /* 标题/强调入场 */
```

- **标题入场**：`bounce-in`（弹跳感）
- **内容入场**：`fade + slideUp`（渐入 + 上移）
- **进度条**：1.2s 延展开，绿色填充
- **导航**：左侧圆点 + 底部彩虹进度条

## 七、引用方式

在制作 HTML 幻灯片时，从本文件中复制以下部分：
1. **配色变量** → 粘贴到 `:root{}` 内

3. **装饰元素** → 写入 CSS class
4. **字体方案** → 引入 Google Fonts
