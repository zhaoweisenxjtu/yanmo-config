# 🎨 清新科技风 (Fresh Tech Deck)

> 基于用户提供的「机器支付四件套」技术框架页解析固化的风格
> 保存日期：2026-05-22
>
> 风格定位：理性 · 克制 · 技术感
> 适用场景：技术方案说明 · 系统架构图 · 方法论框架 · 白皮书/研究报告 · 产品技术页
>
> **核心设计心法**：「克制的信息可视化」。
> 全幅对称布局，低饱和冷色系分层，靠色块明度差异而非线条边框来分区，
> 一页塞进框架全貌，适合技术概念一次性讲透的场景。

## 一、色彩系统（Color System）

```css
:root {
    /* === 背景 === */
    --bg-primary:        #ffffff;      /* 纯白基底 — 主背景 */
    --bg-page:           #fcfdff;      /* 页边缘微蓝渐变过渡 */
    --bg-card:           #ffffff;      /* 卡片/模块背景 — 纯白 */

    /* === 卡片底色（极浅冷色系分层） === */
    --bg-blue-frost:     #ecf2fe;      /* 雾蓝 — 最常用的卡片底色/表头 */
    --bg-blue-light:     #e9f3ff;      /* 淡蓝 — 辅助卡片/标签 */
    --bg-blue-pale:      #e5f1ff;      /* 极浅蓝 — 二级分区 */
    --bg-mint:           #e8fbf5;      /* 冰薄荷 — 底部场景区/对比色块 */
    --bg-mint-light:     #e8fbf7;      /* 浅薄荷 — 辅助薄荷区 */
    --bg-lavender:       #eff1fe;      /* 淡紫灰 — 装饰/特殊标注区 */
    --bg-lavender-light: #eef5ff;      /* 浅紫蓝 — 过渡色 */

    /* === 顶部装饰色（渐变过渡） === */
    --header-start:      #f4f8ff;      /* 顶部渐变起点 — 亮冰蓝 */
    --header-end:        #ecf2fe;      /* 顶部渐变终点 — 雾蓝 */

    /* === 底部横条/装饰 === */
    --footer-blue:       #ecf2fe;      /* 底部蓝 */
    --footer-mint:       #e2fbf7;      /* 底部青（与蓝色渐变的端点） */

    /* === 左侧极浅装饰带 === */
    --edge-blue:         #fafbff;      /* 左右边缘极浅蓝紫 */

    /* === 文字色 === */
    --text-primary:      #1a1f2e;      /* 主文字 — 接近纯黑的海军 */
    --text-secondary:    #4a5064;      /* 副文字 — 深灰 */
    --text-muted:        #8e93a4;      /* 弱文字 — 注释/辅助信息 */
    --text-on-light:     #3a4a5e;      /* 浅色背景上文字 — 深蓝灰 */

    /* === 强调/标注色 === */
    --accent-blue:       #4a7bd0;      /* 强调蓝 — 图标/链接/关键值 */
    --accent-blue-mid:   #6090e0;      /* 中蓝 — hover/active */
    --accent-teal:       #5bbfa0;      /* 青绿 — 可选强调（冷系中跳出来） */
    --accent-dark:       #1a2d4a;      /* 深蓝 — 标题/重点标签背景 */

    /* === 边框与分割 === */
    --border-subtle:     #e8ebf0;      /* 极淡分割线 */
    --border-card:       #eef2f8;      /* 卡片边缘 */
}
```

**配色逻辑**：
- 🤍 白色 + 极浅冷色 → 通透 · 干净 · 技术感
- 🔵 雾蓝家族（ecf2fe → e5f1ff）→ 理性 · 专业 · 克制冷色基底
- 🌿 冰薄荷家族（e8fbf5 → e2fbf7）→ 清新 · 对比分区
- 🔮 淡紫灰（eff1fe）→ 柔和过渡，增加层次
- 无暖色，保持高度冷色统一

## 二、布局规范（Layout System）

### 2.1 页面比例

```
┌────────────────────────────────────────────┐
│  ░░ 冰蓝顶渐变带 ░░  ← h: 约5-8%          │
│                                            │
│  ┌── 大标题 ────────────────────────────┐  │
│  │ 机器支付四件套: KYA - FAPI 2.0 - ... │  │
│  │ [副标题/标签行 更小字号]             │  │
│  └─────────────────────────────────────┘  │
│                                            │
│  ┌────────────┐  ┌────────────┐           │
│  │  模块 1     │  │  模块 2     │  ← 2×2  │
│  │  (白色卡片)  │  │  (白色卡片)  │    网格  │
│  ├────────────┤  ├────────────┤           │
│  │  模块 3     │  │  模块 4     │           │
│  │  (白色卡片)  │  │  (白色卡片)  │           │
│  └────────────┘  └────────────┘           │
│                                            │
│  ┌── 场景区（薄荷底）────────────────────┐  │
│  │  ┌─场景A──┐  ┌─场景B──┐               │  │
│  │  │ 大额   │  │ 小额   │  ← 底部并排   │  │
│  │  └────────┘  └────────┘               │  │
│  └─────────────────────────────────────┘  │
│                                            │
│  ░░ 蓝→青渐变底带 ░░                       │
└────────────────────────────────────────────┘
```

### 2.2 核心布局规则

| 规则 | 描述 |
|------|------|
| **全幅对称** | 页面内容水平居中，左右等宽留白 |
| **多块网格** | 2×2 / 3×2 等模块化网格，比例均分 |
| **顶部标题区** | 居中大标题 + 下方辅助文字行，两端留白 |
| **底部场景/对比区** | 跨栏并排卡片，用不同底色区分（薄荷 vs 蓝） |
| **无装饰区** | 不设独立的装饰列/装饰区，所有空间用于内容 |
| **卡片内留白** | 卡片内部 padding 充足，保证高密度信息不拥挤 |

### 2.3 每页内容密度限制

| 页面类型 | 最大内容 |
|----------|---------|
| 框架总览页 | 1 标题 + 1 副标题 + 2×2或3×2 卡片网格 + 底部对比 |
| 卡片内部 | 1 卡片标题 + 嵌套子项 ≤ 6 条 + 关联标注线 |
| 对比/场景页 | 2 组并排卡片 + 每组 ≤ 5 要点 |
| 纯技术说明 | 同框架页密度，允许信息饱满 |

## 三、排版规范（Typography System）

### 3.1 字体方案

```css
/* 全无衬线 — 保持科技感、克制 */
--font-display: 'Inter', 'Noto Sans SC', sans-serif;
--font-body:    'Inter', 'Noto Sans SC', sans-serif;
--font-mono:    'JetBrains Mono', 'Fira Code', monospace;  /* 代码/参数 */
```

### 3.2 字号缩放（clamp 规则）

```css
--title-size:   clamp(1.3rem, 3.5vw, 2.8rem);   /* 页面大标题 */
--subtitle-size: clamp(0.75rem, 1.8vw, 1.2rem); /* 副标题/标签行 */
--card-title:   clamp(0.95rem, 1.8vw, 1.4rem);  /* 卡片标题 */
--card-sub:     clamp(0.7rem, 1.2vw, 0.95rem);  /* 卡片子项标题 */
--body-size:    clamp(0.65rem, 1vw, 0.85rem);   /* 卡片正文/说明 */
--small-size:   clamp(0.55rem, 0.85vw, 0.75rem);/* 辅助文字/标注 */
--tiny-size:    clamp(0.45rem, 0.7vw, 0.65rem); /* 来源/注释 */
```

### 3.3 间距系统（6分网格 — 密度略高于8分格）

```css
--slide-padding: clamp(1.5rem, 4vw, 3rem);      /* 页面内边距 */
--grid-gap:      clamp(0.5rem, 1.2vw, 1.2rem);  /* 网格卡片间距 */
--card-padding:  clamp(0.6rem, 1.2vw, 1.2rem);  /* 卡片内边距 */
--card-gap:      clamp(0.3rem, 0.6vw, 0.7rem);  /* 卡片内元素间距 */
--item-gap:      clamp(0.2rem, 0.4vw, 0.5rem);  /* 列表项之间 */
--section-gap:   clamp(0.4rem, 1vw, 1rem);      /* 大区块间距 */
```

## 四、视觉元素规范（Visual Elements）

### 4.1 卡片与容器（核心视觉单元）

```
┌─ 白色卡片 ─────────────────────┐
│                                 │
│  📦 模块标题（粗体，深蓝）       │
│  ── 极淡分割线（可选）          │
│                                 │
│  子项 1 ─── 说明文字           │
│  子项 2 ─── 说明文字           │
│  子项 3 ─── 说明文字           │
│                                 │
│  [标注标签]                     │
│                                 │
│  卡片特点：                      │
│  · 纯白底                         │
│  · 无边框（完全靠背景色对比）    │
│  · 圆角 8-10px                   │
│  · 极淡阴影（可选 0 2px 8px     │
│    rgba(0,0,0,0.04)）            │
└─────────────────────────────────┘
```

### 4.2 色块分区（背景切换标识不同区域）

| 区域 | 底色 | 用途 |
|------|------|------|
| 核心卡片 | `#ffffff`（白色） | 正文内容容器 |
| 页面基底 | `#fcfdff`（白→微蓝） | 页面背景 |
| 卡片标签/子容器 | `#ecf2fe`（雾蓝） | 分类/标签/分类背景 |
| 对比场景区 A | `#e8fbf5`（冰薄荷） | 与蓝色卡片产生对比 |
| 对比场景区 B | `#eff1fe`（淡紫灰） | 次要场景/辅助说明 |
| 场景内子卡片 | `#ffffff` + 极淡阴影 | 场景下的具体条目 |

### 4.3 标签系统

```
┌─────────────────────────┐
│  [🔵 标签]  [🌿 标签]   │  ← pill 式标签
│                         │  border-radius: 4px
│  或用色块标识:           │  font-size: small
│  ┌──────┐               │  padding: 2px 8px
│  │ KYA  │               │  底色: #e5f1ff 或 #e8fbf5
│  └──────┘               │
└─────────────────────────┘
```

### 4.4 关联/连接线

- 卡片间的关系可用极淡 `#dce6f0` 虚线连接
- 线宽 1px，虚线间隔 4px
- 箭头用小三角（色值同 accent-blue）

### 4.5 装饰元素

```
保留最小化装饰原则：

┌─ 色块装饰（可选，极克制）───┐
│                               │
│  ◇ 色阶装饰方块（8×8px 小方块 │
│     排成行，蓝→青渐变排列）    │
│                               │
│  — 极淡水平分割线             │
│    width: 40-60%;             │
│    height: 1px;               │
│    background: #dce6f0;       │
│    margin: 0 auto;            │
│                               │
│  ☐ 左上角或右上角低调色块     │
│    （极浅雾蓝, 圆角）          │
└───────────────────────────────┘
```

**无装饰原则**：
- 不设独立的装饰区/装饰列（与 Brand Deck 相反）
- 所有视觉层次靠背景色明度对比和结构化排版实现
- 图片/图标最简化，仅在需要标识时有节制使用

## 六、与默认风格对比

| 维度 | 现代品牌风 (Brand Deck) | 清新科技风 (Fresh Tech) |
|------|------------------------|------------------------|
| **色调** | 海军蓝 + 烤橙 + 鲑鱼粉（暖冷对冲） | 雾蓝 + 冰薄荷 + 淡紫灰（冷色系） |
| **饱和度** | 高对比，强视觉冲击 | 低饱和，克制柔和 |
| **布局** | 非对称（左1/3装饰+右2/3内容） | 全幅对称/模块网格 |
| **字体** | 衬线标题 + 无衬线正文 | 全无衬线（全Sans） |
| **装饰** | 几何色块/贴纸/圆点高装饰 | 无装饰区，靠色块明度分层 |
| **卡片** | 白卡 + 左边框色条 | 白卡 + 纯背景对比 |
| **信息密度** | 中低密度，每页5-6点 | 中高密度，一页可塞框架全貌 |
| **适用** | 品牌/故事/解决方案 | 技术方案/架构/白皮书 |

## 七、引用方式

在制作技术框架类 HTML 幻灯片时，从本文件中复制以下部分：
1. **配色变量** → 粘贴到 `:root{}` 内
2. **布局规则** → 用作页面结构参考
3. **卡片规范** → 写入 CSS class
4. **字体方案** → 引入 Google Fonts（Inter + Noto Sans SC）

### 快速引用命令

```bash
# 在技术框架类 PPT 任务中引用此风格：
参考样式文件: ~/.openclaw/workspace/styles/fresh-tech-deck.md
```
