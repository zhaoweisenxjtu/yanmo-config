# 十层深度分析体系

> 整合麦肯锡、BCG、波特方法论，10 层递进从宏观到战略输出
> 适用范围：投资决策、产品立项、战略规划、竞品分析
> 场景裁剪规则见文末

---

## Layer 1: PESTLE 宏观环境扫描
*政治/经济/社会/技术/法律/环境*
- 政策面：产业政策、监管动向、补贴/税收优惠
- 经济面：GDP、利率、汇率、通胀、产业结构
- 社会面：人口结构、消费趋势、生活方式变迁
- 技术面：关键技术演进、专利趋势、研发投入
- 法律面：行业法规、合规要求、知识产权
- 环境面：双碳政策、ESG、绿色转型压力

## Layer 2: TAM/SAM/SOM 市场规模测算
- TAM (Total Addressable Market)：市场天花板
- SAM (Serviceable Available Market)：可服务市场
- SOM (Serviceable Obtainable Market)：可获得市场
- 测算方法：自顶向下（宏观数据拆解）/自底向上（微观单元加总）

## Layer 3: 波特五力 + 价值链分析
- 供应商议价能力、购买者议价能力、新进入者威胁、替代品威胁、同业竞争
- 行业价值链拆解：核心环节利润池分析

## Layer 4: 竞争格局 + 护城河分析
- 市场集中度（CR4/HHI）、竞争梯队划分
- 护城河来源：技术壁垒/品牌/网络效应/规模优势/转换成本

## Layer 5: JTBD + 用户画像
- Jobs To Be Done 框架：功能性/社会性/情感性任务
- 典型用户画像：决策链角色分析

## Layer 6: S曲线 + 专利地图
- 技术成熟度曲线、产品生命周期
- 关键专利分析：数量/质量/布局/壁垒

## Layer 7: 财务基准 + 资本市场
- 行业平均毛利率/净利率/ROE
- 可比公司分析、估值倍数
- 并购/融资动态

## Layer 8: SWOT + 情景规划 + 战略选项
- 优势/劣势/机会/威胁
- 3-5 年情景推演（乐观/基准/悲观）
- 战略选项矩阵
